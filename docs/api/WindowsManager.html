WindowsManager

new WindowsManager()

Description:

  • Manages floating windows for the whiteboard application. Handles window creation, positioning, z-index management, and window controls (minimize, maximize, close, drag, resize).

createWindow(titleopt, contentopt, optionsopt) → {number|null}

Description:

  • Creates a new floating window with the specified title and content. Windows are automatically positioned with cascading offsets if no position is specified.

Source:
  • windows.js, line 85
Examples
const windowId = windowsManager.createWindow('My Window', 'Hello World');
const windowId = windowsManager.createWindow('Custom', content, {
  x: 200,
  y: 150,
  width: 500,
  height: 400
});
Parameters:
Name Type Attributes Default Description
title string <optional>
 'New Window'

The title for the window
content string | HTMLElement <optional>
 ''

The content to display (string or DOM element)
options WindowOptions <optional>
 {}

Optional positioning and sizing options
Returns:

The ID of the created window, or null if creation failed
